# Камилла Бородина — сайт-резюме

Адаптивный сайт на русском языке: опыт работы, достижения, экспертиза и профиль GitHub. Без внешних библиотек и сборки.

## Просмотр

Откройте `dist/index.html` в браузере или запустите `python3 -m http.server 8080 --directory dist`.

Кнопка «Сохранить в PDF» открывает диалог печати браузера. Выберите сохранение в PDF.

## Редактирование

Весь контент и оформление находятся в `dist/index.html`. Email и телефон не добавлены: они не предоставлены для публикации.
